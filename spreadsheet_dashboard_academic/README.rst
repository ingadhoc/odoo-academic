==============================
Spreadsheet Dashboard Academic
==============================

This module adds the "Seguimiento de Facturación" (billing tracking) spreadsheet dashboard, in a new "Academic" dashboard group.

The dashboard shows:

* the number of students, parents and inactive students, and students by current course and level (initial, primary, secondary);
* subscriptions by recurring plan for each level;
* monthly invoicing and monthly payments, and monthly collections for the current year;
* the list of recurring plans.

The dashboard is shared with the Academic manager group.

#. Only need to install the module

=====

To use this module, you need to:

#. Go to Dashboards > Academic > Seguimiento de Facturación.
